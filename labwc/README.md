# labwc

Patch stack on top of upstream Labwc tags, one file per patch with a "why" header
(the scheme of grigio/labwc-blur). First goal: link against scenefx 0.5 (libscenefx-0.5 in
Debian Forky) for rounded corners and soft shadows. Nothing here yet.
